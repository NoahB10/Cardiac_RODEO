===============================================================================
3. PROCESSING PIPELINE (per well)
===============================================================================

Each well's raw time series goes through 5 steps:

Step 1 — SPIKE REMOVAL (first pass, threshold_mult=5.0)
  - Compute median absolute step size across the time series
  - For each interior point, compare deviation from neighbor average
  - Mark as spike if: deviation > 5x median step AND > 2x neighbor difference
  - Replace spikes with NaN, then linearly interpolate across them

Step 2 — NaN GAP CHECK (MAX_NAN_GAP=7)
  - If any consecutive NaN run exceeds 7 timestamps, EXCLUDE the well entirely
  - Otherwise, linearly interpolate to fill all NaN gaps

Step 3 — SPIKE REMOVAL (second pass, threshold_mult=2.5)
  - More aggressive — catches smaller spikes missed in step 1
  - Same algorithm, lower threshold

Step 4 — FINAL NaN FILL
  - Any remaining NaN filled by linear interpolation
  - Wells with fewer than 4 valid points excluded entirely

Step 5 — INTENSIVE SMOOTHING
  a. LOWESS pass 1: frac=0.55 (very broad, captures overall trend)
  b. LOWESS pass 2: frac=0.45 (moderate)
  c. LOWESS pass 3: frac=0.35 (narrower, refines shape)
  d. Gaussian filter: sigma=3.0 (removes residual jitter)
  e. CubicSpline: bc_type=((1, 0.0), (2, 0.0))
     - Left boundary: clamped (zero slope at t=0, flat baseline start)
     - Right boundary: natural (free curvature)
  f. Evaluate on 1000-point fine grid for smooth output curves

This is very heavy smoothing — it removes all measurement noise and produces
publication-quality curves showing only the overall trend.


===============================================================================
4. BASELINE OFFSET (averaged plot)
===============================================================================

The averaged plot uses a compressed-offset approach so that all concentration
traces start at approximately the same point:

  1. Process all wells through the smoothing pipeline
  2. For each concentration, compute the average smoothed start value
     (mean of v_fine[0] across all wells at that concentration)
  3. Compute the global average start across all concentrations
  4. Apply compression factor COMPRESS=0.3:
       adjusted_start[c] = global_avg + 0.3 * (conc_avg_start[c] - global_avg)
     This pulls each concentration's start toward the global mean while
     preserving 30% of the original spread (fully collapsed would be 0.0,
     no change would be 1.0)
  5. Offset each individual trace before averaging:
       v_offset = v - (v[0] - adjusted_start[conc])
  6. Average the offset traces per concentration

This removes the confounding effect of different wells/concentrations starting
at different baselines, making the dose-dependent divergence clearly visible.

===============================================================================
6. HIGH-BASELINE OFFSET
===============================================================================

n_high_baseline = 0 for Mexiletine (disabled).

This feature shifts the N highest-baseline wells down to match the average
of the remaining wells. It was not needed for Mexiletine because the
compressed-offset approach (Section 4) handled baseline variation adequately.
