Processing Pipeline
-------------------
  1. Load CSV (rows=time, columns=wells)
  2. Drop excluded wells (by index and by column name)
  3. Interpolate NaN gaps (linear, limit=10, both directions)
  4. LOWESS w=16 per-well along time — FULL smoothing (including first point)
     - statsmodels.nonparametric.smoothers_lowess.lowess
     - frac = min(1.0, max(16, 1) / len(valid))
     - ALL points smoothed (first point NOT preserved)
     - Each well smoothed independently (no cross-concentration smoothing)
  5. Transpose for heatmap (rows=wells, cols=time)
  6. Sort within each concentration group by average value descending
     (highest avg at top, lowest at bottom = ascending bottom-up)
  7. Scale contractility by 100 (display as x10^-2)

  NOTE: The key difference from earlier heatmap versions is step 4 —
  the first timepoint is smoothed along with all others, not preserved
  as a raw value. This eliminates the abrupt baseline color jump that
  appeared in earlier versions.

    REMOVE_ORIGINAL = {4, 5, 6, 7, 14, 15, 17, 21, 22, 24, 26}  # 1-based indices
    REMOVE_COLS_EXTRA = {'20', '2.5.1', '2.5'}                    # CSV column names

  Pipeline:
    df = pd.read_csv('Cleaned_Data/Raw_Example_Data/Mexiletine/Amp_std.csv', index_col=0)
    # Drop by index
    keep_cols = [col for i, col in enumerate(df.columns) if (i+1) not in REMOVE_ORIGINAL]
    keep_cols = [col for col in keep_cols if col not in REMOVE_COLS_EXTRA]
    df = df[keep_cols]
    # Interpolate
    for col in df.columns:
        df[col] = df[col].interpolate(method='linear', limit=10, limit_direction='both')
    # LOWESS full (no first-point preservation)
    apply_lowess_full(df, window=16)
