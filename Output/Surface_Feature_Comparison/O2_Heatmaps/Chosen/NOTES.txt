Chosen O2 Heatmaps — Generation Notes
=======================================

These heatmaps are the reviewed/curated versions used for Figure 3a.
Generated by: Cleaned_Data/Raw_Example_Data/plot_all_o2_heatmaps.py

Pipeline (same as Figure 2 heatmaps):
  1. Load sorted O2 CSV from Cleaned_Data/Heatmaps/{Drug}/O2_mean_sorted.csv
  2. Remove outlier data points (O2 > 80 or < 0 → NaN)
  3. Drop wells with > 50% NaN
  4. Linear interpolation within each well (limit=10)
  5. LOWESS smoothing (w=16) per-well along time
  6. Remove manually flagged rows (see below)
  7. Transpose → plot with blue-white-red colormap (#123BFF → white → #FF2908)
  8. Clip O2 values at 100

Colormap range: vmin=0, vmax=100
DPI: 600

Rows Removed (1-indexed, from sorted well order)
-------------------------------------------------

Doxorubicin:    rows {9, 12}
Nifedipine:     rows {5, 6}
Dactinomycin:   rows {1, 8, 12, 16, 20, 24, 27}
Mexiletine:     rows {2, 3, 9, 13, 20}

These row numbers refer to the position BEFORE removal, in the sorted
ascending bottom-up well order within each concentration group.

The _NUMBERED.png versions show each row with its index for review.
The clean versions (in Output/PowerPoint_Figures/Fig_3/) have axis labels
("Drug Dose" / "Time from Exposure (h)") but no tick values, no colorbar.

To regenerate:
  cd Cleaned_Data/Raw_Example_Data
  python -c "import plot_all_o2_heatmaps as p; p.generate_heatmap('Mexiletine', 'Mexiletine')"

Or regenerate all chosen drugs:
  python plot_all_o2_heatmaps.py

Row skip config is in DRUG_SKIP_ROWS dict in plot_all_o2_heatmaps.py.
Chosen drugs are in FIG3_CHOSEN set in the same file.
