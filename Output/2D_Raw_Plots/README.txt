2D Raw Time-Series Plots — Process Notes
=========================================

Generated by: generate_2d_raw_plots.py
Date: 2026-03-12

PURPOSE
-------
Visualize averaged time-series data for all 23 drugs, with one line per
concentration, color-coded by dose (plasma colormap, high→low).

DATA SOURCES
------------
- O2:             Cleaned_Data/O2_Mean_Averaged.xlsx
- Contractility:  Cleaned_Data/Heart_Contractility_Averaged.xlsx

These files contain simple means of replicate wells (pre-averaged, no
smoothing applied at the source level).

SKIPPED DRUGS
-------------
Panobinostat, Vioxx — averaged data doesn't match raw wells (possible
well exclusion issues).

TWO OUTPUT MODES
----------------
1. Normalized/  — Each trace divided by its baseline (mean of first 3
   time points). Y-axis = "fraction of baseline". All traces start at ~1.0.

2. Baseline_Aligned/  — Each trace has baseline subtracted, then the
   entire plot is shifted up so no values are ≤ 0 (global minimum set to
   0.01). Y-axis = "O2 (%)" or "Contractility" in original units relative
   to baseline.

PROCESSING PIPELINE (per concentration trace)
----------------------------------------------
1. Manual spike removal (Epirubicin O2 only):
   - ('Epirubicin', 'O2', '0.094'): indices [15-19] — ramp artifact t=40-51h
   - ('Epirubicin', 'O2', '0.38'):  indices [5, 18, 19, 33, 36]
   NaN'd and linearly interpolated.

2. Automatic spike removal — Pass 1 (threshold_mult=5.0):
   - Single-point detector: compares each point to average of its 2
     immediate neighbors. Flags if deviation > 5× median step size AND
     > 2× neighbor difference.
   - Rolling median detector (±3 window): compares each point to local
     median. Flags if deviation > 3× MAD or > 2.5× median step size.
   - Flagged points replaced with NaN, then linearly interpolated.

3. Baseline alignment:
   - Normalize mode: divide by mean of first 3 points (fraction of baseline)
   - Offset mode: subtract mean of first 3 points

4. Automatic spike removal — Pass 2 (threshold_mult=3.0):
   More aggressive second pass on the aligned data to catch spikes that
   were only apparent after normalization/offset.

5. LOWESS smoothing:
   - statsmodels.nonparametric.lowess with frac=0.2
   - Light smoothing to reduce noise while preserving trends

6. Zero-value shift (offset mode only):
   - Find global minimum across all concentrations for the drug
   - If ≤ 0, shift all traces up by |global_min| + 0.01

PLOT SETTINGS
-------------
- Figure size: 4 × 2.8 inches
- DPI: 600
- Colormap: plasma (high concentration = warm, low = cool)
- Legend: outside right, sorted high→low concentration
- X-axis: 0–96 hours
- Font: Helvetica (via figure_config.py)

- Arrhythmia_and_HeartDamage/  (12 drugs)
- Arrhythmia_Only/             (1 drug)
