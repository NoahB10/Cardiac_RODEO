Figure 2 Heatmap Options — Production Notes
=============================================

6 candidate heatmaps for Figure 2 (pick 1 O2 + 1 Contractility).

All use the same processing pipeline:
  1. Load sorted CSV from Cleaned_Data/Heatmaps/{Drug}/
     (wells sorted ascending bottom-up within each concentration group)
  2. Drop excluded wells (listed below per drug)
  3. Interpolate NaN gaps (linear, limit=10, both directions)
  4. LOWESS w=16 per-well along time (no cross-concentration smoothing)
     - statsmodels.nonparametric.smoothers_lowess.lowess
     - frac = min(1.0, max(16, 1) / len(to_smooth))
     - First time point preserved (not smoothed)
  5. Transpose for heatmap (rows=wells, cols=time)
  6. O2: clip at 100; Contractility: scale by 100

Plot settings: Blue (#123BFF) -> White -> Red (#FF2908), square cells,
linewidths=0, DPI=600, one centered tick per concentration group.
